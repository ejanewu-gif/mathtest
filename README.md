# 臺南市國小數學科歷年學力檢測題庫系統 (109～114年 全年級)

線上查閱系統：[https://ejanewu-gif.github.io/mathtest/](https://ejanewu-gif.github.io/mathtest/)

---

### 專案簡介
本系統收錄 **109 年至 114 年臺南市國小數學科歷年學力檢測** 所有試題，並全面接軌 **108 課綱學習內容條目**，專為教育研究者、命題教師與教學輔導團隊設計。

### 收錄規格
- **涵蓋年級**：國小三年級、四年級、五年級、六年級（共 4 個年級）
- **試題總數**：**598 題**
- **題目圖片**：**603 張** 高清題目與圖表裁切圖檔
- **分析內容**：完整收錄官方評量目標、低分組選答率、迷思概念分析與補救教學建議

### 核心功能
1. **指標快速對照**：點選任一 108 課綱條目（如 N-3-2、N-4-5、N-5-3、S-6-3），即刻橫向展開 6 年來該指標出過的所有試題。
2. **題目燈箱放大**：點擊卡片中的題目圖片即可全螢幕放大清晰檢視。
3. **低分組迷思抽屜**：展開每題下方之「試題表現與迷思分析」，快速掌握學童常犯概念混淆。
4. **即時檢索**：支援關鍵字、指標代號、年份秒級過濾。
